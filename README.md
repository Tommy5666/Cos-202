COS202 Python Programming Assignment

This repository contains two Python programs developed for my COS202 coursework at Adekunle Ajasin University.

Programs

1. Mathematical Calculator ("calculator.py") — Performs basic mathematical operations such as addition, subtraction, multiplication, and division.
2. Personal Pocket CGPA Calculator ("cgpa.py") — Calculates a student's CGPA based on course units and scores.
